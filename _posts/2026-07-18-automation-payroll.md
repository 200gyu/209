> 매월 말이면 **근태 엑셀을 취합하고, 수당을 계산하고, 명세서를 한 장씩** 만드느라 며칠이 갑니다. 규칙이 정해진 이 작업은 자동화가 가장 확실하게 돈을 버는 지점입니다.
{: .prompt-info }

## 🎯 무엇이 자동화되나

- 📥 지점·부서별 **근태 엑셀 취합**
- 🧮 기본급·연장/야간·공제 **규칙대로 계산**
- 📄 직원별 **급여명세서 대량 생성**(PDF/문서)

## ⚙️ 흐름

```mermaid
flowchart LR
    A[근태 엑셀들] --> B[취합·정규화]
    B --> C[수당·공제 계산<br/>규칙 적용]
    C --> D[명세서 대량 생성]
    D --> E[사람 검수·배포]
```

## 🛠️ 파이썬 예시 (취합 + 계산)

```python
import pandas as pd, glob

# 1) 여러 근태 파일 취합
df = pd.concat([pd.read_excel(f) for f in glob.glob("근태/*.xlsx")],
               ignore_index=True)

# 2) 규칙대로 수당 계산 (예시 규칙)
HOURLY = 12000
df["연장수당"] = df["연장시간"] * HOURLY * 1.5   # 연장 1.5배
df["지급합계"] = df["기본급"] + df["연장수당"]
df["실지급액"] = df["지급합계"] - df["공제액"]

# 3) 직원별 요약 저장
df.to_excel("급여_정산_2026-07.xlsx", index=False)
```

명세서 문서 대량 생성은 [문서 자동 생성]({% post_url 2026-07-16-automation-doc-generation %}) 패턴을 그대로 씁니다(이름·금액만 바꿔 100장).

## ⚠️ 반드시 주의

- **4대보험·소득세** 등 법정 공제는 규정이 자주 바뀌고 복잡합니다 → **자동 계산 후 반드시 검증**, 필요 시 노무·세무 전문가 확인.
- **개인정보(급여)** 는 접근 권한·보관을 엄격히.
- 규칙은 **코드로 고정**해 매달 같은 기준 적용(휴먼 에러 제거).

## 📋 입력 파일 표준화가 절반입니다

자동화가 실패하는 가장 흔한 이유는 계산이 아니라 **들어오는 엑셀 양식이 제각각**이라서입니다. 먼저 양식을 하나로 정합니다.

| 열 이름 | 예시 | 규칙 |
|---------|------|------|
| 사번 | E0012 | 필수, 중복 불가 |
| 근무일 | 2026-07-03 | 날짜 형식 고정 |
| 출근 / 퇴근 | 09:00 / 18:30 | 24시간제 |
| 휴게(분) | 60 | 숫자 |
| 구분 | 평일 / 휴일 | 선택값만 |

양식이 다른 지점은 **열 이름 매핑표**를 만들어 취합 단계에서 같은 이름으로 바꿔줍니다.

## 🔍 계산 전에 반드시 검증하는 3가지

```python
required = ["사번", "근무일", "출근", "퇴근"]
missing = [c for c in required if c not in df.columns]
assert not missing, f"필수 열 누락: {missing}"          # 1) 양식 검증

df["근무일"] = pd.to_datetime(df["근무일"], errors="coerce")
bad_dates = df[df["근무일"].isna()]                      # 2) 날짜 오류 행
dup = df[df.duplicated(["사번", "근무일"], keep=False)]  # 3) 같은 날 중복 입력
```

검증에 걸린 행은 계산하지 말고 **오류 목록 파일**로 따로 내보내 담당자가 먼저 고치게 합니다. 틀린 입력으로 계산한 결과는 맞게 보이기 때문에 더 위험합니다.

## ⚙️ 수당 규칙은 코드 밖으로 빼두세요

```python
RULES = {
    "시급": 12000,
    "연장_가산": 1.5,   # 예시 값: 사업장 규정·근로형태에 맞게 확인
    "야간_가산": 1.5,
    "휴일_가산": 1.5,
}
```

규칙을 한곳에 모으면 **임금 체계가 바뀌어도 값만 고치면** 되고, 감사나 질문이 들어왔을 때 "이 기준으로 계산했다"고 보여줄 수 있습니다. 가산 비율과 적용 여부는 사업장 규모(예: 5인 미만 사업장 등)와 근로 형태에 따라 달라지므로 **노무 전문가에게 기준을 확인한 뒤** 값을 정하세요.

## 🧐 사람이 볼 것만 골라주는 검수 리포트

전부 다시 보는 대신, 이상한 사람만 뽑으면 검수가 10분으로 줄어듭니다.

- 전월 대비 **지급액이 20% 이상 늘거나 줄어든 직원**
- 하루 **12시간 이상** 근무로 입력된 날이 있는 직원
- 신규 입사·퇴사·휴직으로 **일할 계산**이 필요한 직원
- 공제액이 0인데 급여가 큰 직원(입력 누락 의심)

이 목록과 함께 "총 지급액 합계"가 전월과 얼마나 다른지만 첫 줄에 보여줘도, 검수자가 판단하기 훨씬 쉬워집니다.

> 📉 **도입 효과 한 줄 요약 (예시 ROI)** — 직원 30명 기준 매월 정산·명세서에 **2~3일** 쓰던 것을 **반나절**로. 담당자 **월 약 15시간** 회수 + 계산 오류 감소. *(예시이며 인원·급여체계에 따라 다릅니다.)*
